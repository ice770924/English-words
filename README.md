# 깜빡이 영단어 (Kkamppagi English) v1.1.0

## 주요 개선 사항
1. **시스템 하단 버튼 겹침 해결 (`WindowInsets` 안전 영역 적용)**
   - Android 11~16의 하단 3버튼 네비게이션 바 및 제스처 바와 앱 버튼(`+ 내 단어 추가`, `✓ 암기완료 제외`)이 절대 겹치지 않도록 자동 여백을 확보했습니다.
2. **내 단어 추가 화면 분리 (직접 입력 + 카메라 사진 스캔)**
   - **✍️ 직접 입력하기:** 영단어, 뜻, 예문을 직접 입력해 저장합니다.
   - **📷 카메라로 찍어 추가:** 영어 책이나 단어장, 프린트물을 촬영(또는 앨범 선택)하면 온디바이스 ML Kit OCR 엔진이 영단어를 자동 추출하여 한 번에 단어장에 추가합니다.
